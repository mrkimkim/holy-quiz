## 19.1 성경 저작권

**원칙**: 성경의 '사실·내용'을 묻는 문제 자체는 아이디어·사실로서 **비보호**(비침해). 그러나 F1(정답 시 근거구절)·F9(근거구절 LLM 입력)는 번역본 **본문을 축자 복제·전송·저장**하므로 저작권 대상. PRD·디자인의 "퀴즈는 라이선스 불필요"는 근거구절 표시에 대해 **오판**이며, 라이선스 게이트(ref_text 분리) 대상은 오늘의말씀만이 아니라 **F1 근거구절·F9 원문 전체**다(server 14.20·content D2 정합, legal 블로커).

**번역본 저작권 상태**

| 번역본 | 권리자 | 상태 | 판단 |
|---|---|---|---|
| 개역개정(1998) | 대한성서공회 | 보호 | 라이선스 필수 |
| 개역한글(1961) | 대한성서공회 | 보호(법인저작물 공표후 70년) | "구본=무료" 오해, 라이선스 필수 |
| 구절 위치만(요 3:16) | 없음 | 사실 표기 | 무라이선스 가능(폴백) |

**실행**: (1) 성서공회에 사용 라이선스 문의(**범위=오늘의말씀+F1 근거구절+F9 원문 전체 통일**, 예상량, 상업 여부). (2) **출시 전 미타결 시 폴백 발동**=근거구절 위치·장·절만 표기, 본문 미표시(content/client 사전 스펙). **판권 표기·폴백(장·절만) UI 슬롯을 오늘의말씀 카드와 퀴즈 근거구절 화면 양쪽에 배치**(design 11.8 슬롯을 퀴즈 화면까지 확장). (3) 오늘의말씀=개역개정으로 확정, 퀴즈 표기와 일원화, 라이선스에 포함. (4) 출시 전 저작권 변호사 검토·계약서 검수 1회.

**의존성**: content(근거구절 데이터 구조를 '위치' 필드 분리 저장, 개역개정 통일), client/design(폴백·판권 슬롯을 오늘의말씀+퀴즈 근거구절 **양 화면**에), ops(계약 관리).

## 19.2 개인정보 — 민감정보(종교) 처리 근거

교회소속·리더보드 참여는 **정보주체의 종교를 드러내므로 PIPA §23 민감정보**. 필수 설계:

1. **별도(선택) 동의·수집 시점**: 종교/교회소속 수집·전국 공개에 대해 일반 동의와 **물리적으로 분리된** 동의창(체크박스 별도, 사전 선택 금지). 수집 시점은 **교회 기능 이용(교회 등록) 직전의 선택 동의**로 두고, **온보딩 진입 필수 게이트로 두지 않음**. 미동의 시 교회 기능만 미제공되고 **개인 퀴즈는 무동의로 이용 가능**(PIPA 강요·번들 금지, 교회등록=스킵 가능 설계와 정합. data 17.11.1·client 13.10 일치).
2. **공개 고지**: "회원님의 닉네임과 소속 교회가 전국/시도/교회 리더보드에 공개됩니다"를 동의 시점에 명시. 실명 강제 금지 → **닉네임 기본**(19.5 아동·미성년 노출 회피).
3. **B2B 자산화·목적외 동의**: 수집 목적(퀴즈 서비스)에 없던 B2B 이용은 §23 목적외. 원칙=**무동의 시 개인식별 데이터 B2B 판매·제공 금지**, 목회자 도구는 **가명·통계처리 데이터만**(예: 교회별 참여자 수·정답률 집계). 자산화 합법화가 필요하면 수집 시점에 **B2B(목적외) 별도 선택 동의**를 신설(거부해도 서비스 이용 가능하도록 시각 분리, 19.3 ⑦). 처리방침·동의서에 "통계 목적 가명처리" 명시. 개인식별 제공이 꼭 필요하면 **별도 제3자 제공 동의** 추가.
4. 최소수집: '종교=개신교' 플래그를 별도 저장하지 않음(교회소속으로 충분, 추가 민감필드 회피).
5. **민감 파생속성 국외전송 금지**: church_id 등 종교 파생 속성을 국외 analytics SDK(GA4/Firebase Analytics, 미국)로 **전송 금지**, server→BigQuery(서울) 경로만 허용. church_id가 GA4로 흐르면 **민감정보의 무동의 국외이전(§23)**이 되므로, 해당 이벤트는 client 래퍼가 GA4로 보내지 않고 서버 소스(S)로만 발행(data 17.4.2/17.5.1·finding4 정합).

**의존성**: server(민감정보 암호화 저장·접근통제 로그, church_id 서버 소스 발행), data(가명처리 파이프라인, church_id GA4 배제·taxonomy 소스 S/C 규칙), monetization/org(B2B 계약 구조·목적외 동의 연계).

## 19.3 개인정보 — 수집항목·동의 설계

**수집 최소화 원칙**으로 항목 확정:

| 항목 | 출처 | 구분 | 비고 |
|---|---|---|---|
| 카카오 회원번호, 닉네임 | 카카오 로그인 | 필수 | 이메일·전화번호 **미수집 권고**(불필요) |
| 생년(연령확인용) | 카카오 | 필수 | 만14세 게이트 판정, 저장 최소화 |
| 교회소속 | 사용자 선택 | **민감(별도·선택)** | 19.2, 교회 등록 시점 수집 |
| 위치/장소검색어 | 교회 검색 시 | 선택 | 좌표 저장 안 함, 검색어만 일시 사용 |
| 기기식별자/광고ID | OS | 선택 | 광고·어뷰징 방어(ATT/동의 연계) |
| 퀴즈·포인트·출석 로그 | 앱 | 필수 | 서비스 이행 |

**동의 화면 분리(체크박스 각각)**: ①이용약관(필수) ②개인정보 수집·이용(필수) ③종교/교회소속 민감정보(별도·**교회 등록 직전 선택 수집**, 온보딩 진입 게이트 아님) ④개인정보 처리위탁·국외이전 고지(AdMob/Firebase) ⑤광고성 정보 수신(선택) ⑥맞춤형 광고(선택) ⑦**B2B/목회자 제공(목적외) 별도 선택 동의**(거부해도 서비스 이용 가능, 시각 분리). 필수 외 미동의도 핵심 퀴즈 이용 가능해야 함(교회 미등록=스킵 가능, 무동의로 개인 퀴즈 이용 가능, PRD 정합). ③⑦ 등 선택 동의는 **온보딩 필수 게이트로 두지 않으며**, 동의화면은 **server가 내려주는 필요 동의 목록 기반**으로 구성(client 13.10 데이터 기반 동의화면과 정합, UX 12.3.1 O2의 '필수·진행 불가' 처리를 이 기준으로 수정).

**국외이전**: AdMob·Firebase(Google, 미국)로 광고ID·이벤트 이전 발생 → 이전받는 자·국가·항목·목적·시점 고지 및 동의(또는 처리방침 공개+위탁 고지 방식). **단, church_id 등 종교 파생 민감속성은 국외 analytics로 이전하지 않음**(server→BigQuery 국내 경로만, §23 민감정보 무동의 국외이전 방지). 카카오는 국내. 처리방침에 위탁·국외이전 표 필수.

**의존성**: client(동의 UI, 중장년용 큰글씨·평이한 문구, server 하달 동의목록 렌더), server(동의 버전·시각 로깅, 필요 동의목록 하달), data(광고ID 취급, church_id GA4 배제).

## 19.5 미성년자·연령게이트

- 만 14세 미만: PIPA §22의2 법정대리인 동의 필요 → v1은 **가입 차단**(카카오 생년 기반 게이트). 안내: "만 14세 미만은 보호자와 함께 이용하세요".

- 아동 맞춤형(행태) 광고 제한: 14세 미만 미가입으로 원천 회피.

**의존성**: client(게이트 UI), server(연령 검증·미성년 결제 플래그).

- **환불·청약철회**: 디지털콘텐츠는 원칙상 청약철회 제한 가능하나 **스토어 환불 정책 경유**가 기본. 앱 내 환불은 "스토어에서 처리" 안내 페이지.
- **미성년자 결제**: 법정대리인 동의 없는 미성년 결제는 취소권 → 결제 전 성인/동의 확인, 취소 요청 CS 플로우.
- **서버 영수증검증**(server 필수): 클라이언트 신호만으로 프리미엄 해제 금지, **스토어 서버 검증(App Store Server API / Google Play Developer API)** 후 권한 부여.
- **세무**: 사업자등록, 부가세(구독=과세), 스토어 처리분 있어도 국내 신고 의무 잔존 → 세무사 자문.

**의존성**: server(영수증검증·프리미엄 권한), monetization(실수령·환불 UX), ops(결제 CS).

## 19.8 광고·ATT·맞춤형/종교 타깃광고

- **iOS ATT**: IDFA 사용(AdMob 맞춤형) 시 ATT 프롬프트 필수. 옵트아웃 다수 → eCPM 하락을 monetization 모델에 반영(비맞춤 폴백).
- **맞춤형 광고 동의**: 개인정보 기반 맞춤광고는 별도 동의·거부수단(19.3 ⑥).
- **종교 타깃 UA**: Meta는 '종교' 민감 관심사 상세타깃 **폐지**. 종교 프레이밍 캠페인은 거부·계정정지 위험. 권고=**지역(교회 밀집)·연령(45+)·룩얼라이크·자사 커스텀오디언스**, 소재에서 특정 교단 지칭 회피. 카카오도 민감 타깃 제한 확인.
- **광고 이벤트와 민감속성 분리**: 광고/analytics 이벤트에 church_id 등 종교 파생속성 미포함(19.2-5·국외이전 정합).

**의존성**: marketing(UA 타깃·소재 컴플라이언스, 이벤트명 매핑 정렬), monetization(ATT 감도), data(광고ID·동의 상태 연계, church_id 배제).

## 19.13 파트 간 인터페이스 요약

- **content**: 근거구절 '위치' 필드 분리(폴백), 개역개정 통일, 라이선스 범위=오늘의말씀+F1+F9.
- **client/ux/design**: 판권·폴백(장·절만) 슬롯을 **오늘의말씀 카드+퀴즈 근거구절 화면 양쪽**에, 분리형 동의 UI(중장년 문구), 종교/교회소속 동의를 **교회 등록 직전 선택 동의**로(온보딩 필수 게이트 금지, 무동의 시 개인 퀴즈 가능), **B2B(목적외) 별도 선택 동의 항목 추가**(거부해도 이용 가능), server 하달 동의목록 기반 렌더, Apple 로그인 병기, 탈퇴 1화면, opt-in 새벽 알람.
- **server**: 민감정보 암호화·접근로그, 동의 버전 로깅·필요 동의목록 하달, church_id 서버 소스(S) 발행, 영수증검증, 파기·가명화 배치, 연령/미성년 플래그, 푸시 시간대 게이트.
- **data**: taxonomy.yaml 단일 진실원 확정(이벤트 소스 S/C·이벤트명 매핑표), **church_id 등 민감 파생속성 GA4/Firebase 국외전송 금지·server→BigQuery(서울)만**, B2B 가명·통계처리, 광고ID·동의 상태 연계, 집계 보존 규칙.
- **monetization/marketing/branding·org**: IAP 실수령·ATT 감도·환불 UX / 종교 비상세타깃 UA·이벤트명 정렬·광고푸시 시간 / 상표 출원류·사업자·통신판매업 / B2B 목적외 동의 연계.
