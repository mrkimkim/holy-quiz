# 11. 디자인(비주얼/UI 시스템)

> **한 줄 목적:** 40~70대 중장년 기독교인이 도움 없이 큰 글씨로 매일 성경 퀴즈를 풀고 "우리 교회"를 응원하도록, 신뢰(블루)와 명예(골드)를 담은 WCAG AA+ 접근성 기반의 단일 디자인 토큰 시스템과 컴포넌트·화면·공유자산 규격을 정의한다.

---

## 11.0 이 문서의 위치와 정합성

본 문서는 PRD 제품 원칙 4가지에 종속되며, 모든 시각 결정은 아래 원칙 중 하나 이상으로 역추적 가능해야 한다.

| PRD 원칙 | 디자인 번역(무엇을 강제하는가) |
|---|---|
| 매일의 습관에 얹는다 | 홈 첫 화면 = 오늘의 말씀 + 출석 + `퀴즈 시작` 단일 대형 CTA. 진입 후 3초 내 퀴즈 시작 가능 |
| 명예로 경쟁한다 | 골드=명예/티어 전용 색. 현금·상점 UI 부재. 포인트는 항상 "점(pt)"으로만 표기, 화폐기호 금지 |
| 교회가 팀이다 | 리더보드·프로필·공유카드에 "우리 교회" 시각 요소를 개인 성취보다 최소 동급 비중으로 배치 |
| 중장년이 기본값이다 | 본문 18sp·버튼 56dp·터치타깃 56dp·탭 3개·깊이 2단계라는 하드 제약을 컴포넌트 레벨에서 강제 |

> **주의:** 이 문서의 컬러/티어 아트워크는 **branding 확정 전 워킹 시스템**이다. 브랜딩 파트가 로고·워드마크·최종 컬러를 확정하면 토큰 값만 교체하고 구조는 유지한다(§11.13 토큰 구조 참조).

## 11.1 디자인 원칙 (중장년 접근성 최우선)

우선순위가 충돌할 때 위에서 아래 순으로 이긴다.

1. **가독성 > 미학.** 여백을 줄여 정보를 더 넣지 않는다. 글씨를 키우고 화면을 넘긴다.
2. **명확성 > 밀도.** 한 화면 한 주요 행동(one primary action per screen). 주 CTA는 화면당 1개, 나머지는 시각 위계를 낮춘다.
3. **큰 터치, 넓은 간격.** 최소 터치타깃 56×56dp, 인접 타깃 간 최소 간격 12dp. 중장년 오터치 방지가 미관보다 우선.
4. **색에 의존하지 않는다.** 정답/오답·순위 변동·상태는 색 + 아이콘 + 텍스트 라벨의 3중 신호(WCAG 1.4.1). 색약(남성 8%)·저조도(새벽) 환경 대응.
5. **놀라게 하지 않는다.** 자동 이동·자동 재생·예측 불가한 애니메이션 금지. 파괴적 행동(교회 변경·구독 취소·탈퇴)은 항상 확인 모달.
6. **아이콘 단독 금지.** 하단 탭·주요 버튼은 아이콘 + 한글 라벨 동시 표기. 아이콘만으로 기능을 표현하지 않는다.
7. **읽는 부담 최소화.** 신고 사유·설정은 원탭 선택. 자유 입력은 선택지로 대체 가능하면 항상 대체.

## 11.2 컬러 시스템 (신뢰·따뜻함, WCAG AA 명시)

### 11.2.1 컨셉
- **신뢰 = 딥 블루(Primary).** 교회·성경의 진중함, 사행성 없는 건전함.
- **명예 = 웜 골드(Accent).** 티어·승급·기여 등 "명예로 경쟁한다" 원칙의 시각 화폐. **골드는 명예 문맥 외 사용 금지**(가격·광고·일반 CTA에 골드 금지 → 사행성/유료 오인 차단).
- **바탕 = 웜 페이퍼(#FAF8F4).** 순백 대신 미색 종이톤으로 눈부심 완화(새벽·노안 대응)와 교회 정서의 따뜻함.

### 11.2.2 대비 목표 (하드 규칙)
| 대상 | 최소 기준 | 본 시스템 목표 |
|---|---|---|
| 본문·필수 텍스트(18sp 이상 non-bold) | AA 4.5:1 | **7:1 (AAA)** — 노안 고려, 핵심 읽기면은 AAA 지향 |
| 대형 텍스트(24sp+ 또는 18.66sp bold) | AA 3:1 | 4.5:1 |
| UI 컴포넌트·의미전달 그래픽·아이콘 | 3:1 | 4.5:1 |
| 포커스 링·상태 경계 | 3:1 | Primary 블루(7.9:1)로 통일 |

### 11.2.4 정답/오답 시각 처리 (색약·교회 정서 대응 — 무채색 확정)
정오 처리는 **색 + 아이콘 + 텍스트 3중 신호**를 공통 유지하되, 오답은 **붉은색 단독·강조를 쓰지 않는다**(색약 대응 + 교회 정서 + 오답의 교정 초점). ux(D3·12.3.2·12.13)의 무채색 권고로 **일원화**한다.

- 정답: `success` 채움 + ✓ 아이콘 + "정답" 라벨.
- 오답: **무채색 처리**(`surfaceAlt` 채움 + `textSecondary` 테두리 2dp) + ✕ 아이콘 + "오답" 라벨 + **정답 선택지를 `success`로 동시 강조**(교정 초점을 정답에 둔다). **error 적색(#C0392B)·브랜딩 테라코타는 퀴즈 오답 상태에 사용 금지** — 적색 계열은 시스템 오류·검증 실패 등에만.
- 순위 변동: 상승 `success`+▲+"+3", 하락 `error`+▼+"-2", 유지 `textMuted`+"–". 화살표·부호·색 3중(리더보드 상태는 퀴즈 오답과 별개 문맥).

> **정렬 요구:** 본 무채색 규정은 **branding 팔레트(오답색 지정 제거 또는 비상태 웜 액센트로 격하)** 및 **ux 문안**과 동일 값을 참조해야 한다. 테라코타(#C7622D)는 퀴즈 정오 상태색이 아닌 브랜드 액센트로만 잔존한다.

## 11.3 타이포그래피

### 11.3.1 서체 (권고: Pretendard)
| 항목 | 결정 | 근거 |
|---|---|---|
| 본문 서체 | **Pretendard (SIL OFL 1.1, 무료 상용)** | 넓은 글자 폭·큰 속공간으로 노안 가독성 우수, 9종 웨이트, **탭형 숫자(tabular figures)** 내장 → 리더보드 점수 정렬 |
| 폴백 | iOS: Apple SD Gothic Neo / Android: Noto Sans KR | 시스템 기본, 로딩 실패 무결점 |
| 숫자 표기 | Pretendard tnum(고정폭) 강제 | 순위·점수 세로 정렬 흔들림 방지 |
| 금지 | 명조/손글씨/장식체를 본문에 사용 금지 | 획 얇음·판독성 저하 |

라이선스 근거: Pretendard·Noto Sans KR 모두 OFL → 앱 임베드·수정·상업 배포 허용, 저작권 표기(설정>오픈소스 라이선스) 필요. **의존: legal** 최종 라이선스 확인 1회.

### 11.3.2 타입 스케일 (기준 18sp, sp = Flutter logical px)
| 역할 | 크기(sp) | 웨이트 | 행간 | 용도 |
|---|---|---|---|---|
| Display | 34 | Bold 700 | 1.2 | 티어명, 대형 점수, 승급 축하 |
| H1 | 28 | Bold 700 | 1.25 | 화면 제목 |
| H2 | 24 | SemiBold 600 | 1.3 | 섹션 제목 |
| H3 | 20 | SemiBold 600 | 1.35 | 카드 제목·리스트 강조 |
| **Question** | **22** | **Medium 500** | **1.5** | **퀴즈 지문(특별 확대)** |
| **Body** | **18(최소)** | **Medium 500** | **1.5** | **기본 본문** |
| **Choice** | **20** | **SemiBold 600** | **1.4** | **선택지 버튼 텍스트** |
| Button | 20 | Bold 700 | 1.0 | 주요 버튼 라벨 |
| Label | 16 | Medium 500 | 1.4 | 비필수 보조 라벨 |
| Caption/Meta | 15 | Regular 400 | 1.4 | 근거구절·날짜 등 비필수 메타(하한) |
| Legal(약관) | 14 | Regular 400 | 1.5 | 동의 고지 최소치, 스크롤 가능 |

규칙: **본문(Body) 이상 = 18sp 하한, 필수 정보에 15sp 미만 금지.** 본문 웨이트는 Regular가 아닌 **Medium(500)** — 얇은 획은 노안에서 흐려 보인다.

### 11.3.3 동적 폰트·글자크기 배율 (단일 배율 테이블 — design 소유)
파트 간 배율 충돌을 없애기 위해 **본 표를 design·ux·client·qa 공통 단일 소스로 확정**한다(§11.13 토큰화).

- **앱 내 글자크기 토글 = 3단계: 보통 1.0 / 크게 1.15(권장) / 아주 크게 1.3.** 온보딩에서 선택(§11.7.6), 설정에서 변경.
- OS 동적 폰트(`textScaleFactor`)를 리플로우로 지원. **앱 배율 × OS 배율의 결합 상한(클램프) = 1.6(단일 확정값).** 1.6 초과 요청은 1.6으로 클램프하되 스크롤로 잘림 방지.
- **전 배율에서 본문 18sp·선택지 버튼 64dp·주버튼 56dp 하한 유지**(텍스트 기준 `min-height` + 여백, 고정 높이 컨테이너 금지).
- **의존: client**가 `MediaQuery.textScaler` **결합 클램프 1.6**·리플로우 구현(기존 1.0/1.2/1.4·[1.0,1.6] → 본 표로 교체), **qa**가 골든/회귀 배율 세트를 **앱 1.0/1.15/1.3 × 결합 상한 1.6**에 정렬(기존 2.0 합격선 폐기 → client 1.6과 정합).

## 11.4 그리드·스페이싱·터치타깃

### 11.4.1 스페이싱 스케일 (4pt 베이스, 8pt 리듬)
`space.1=4 · space.2=8 · space.3=12 · space.4=16 · space.5=20 · space.6=24 · space.8=32 · space.10=40 · space.12=48 · space.16=64`

| 용도 | 값 |
|---|---|
| 화면 좌우 여백(gutter) | 20 |
| 카드 내부 패딩 | 20 |
| 카드 간 간격 | 12 |
| 섹션 간 간격 | 32 |
| 인접 터치타깃 최소 간격 | 12 |
| 콘텐츠 최대 폭(태블릿/대화면) | 480 (중앙 정렬) |

### 11.4.2 반경·엘리베이션
- 반경: `sm 8 · md 12 · lg 16 · xl 24 · pill 999`. 카드=16, 버튼=12, 시트 상단=24.
- 엘리베이션(라이트): `e1` 카드(y2·blur8·#000 6%), `e2` 바텀시트(y-4·blur16·8%), `e3` 모달(y8·blur24·10%). 남용 금지 — 그림자보다 `surfaceAlt` 대비로 위계.

### 11.4.3 터치타깃 (하드 규칙)
| 컴포넌트 | 최소 높이/크기 |
|---|---|
| 주요 버튼(Primary/Secondary) | **56dp** |
| 선택지 버튼(Choice) | **64dp** |
| 리스트 행(탭 가능) | 64dp |
| 하단 탭 아이템 | 64dp(+ safe area) |
| 아이콘 버튼 | 시각 아이콘 28 + **탭 영역 48×48 이상** |
| 텍스트 링크 | 탭 영역 44 이상, 인접 12 간격 |

**의존: ux**가 화면별 인터랙션·상태 전이 상세를, **client**가 `InkWell`/`Semantics` 최소 크기 강제.

## 11.5 아이콘·일러스트 방향

### 11.5.1 아이콘
- **스타일: Rounded, 굵은 획(2.5px 기준), 최소 렌더 28dp.** 얇은 라인 아이콘 금지(노안 판독 저하).
- 세트 권고: **Material Symbols Rounded (Apache 2.0)** weight 500 fill 0~1 혼용, 또는 Phosphor(MIT). 라이선스 무료 상용.
- 아이콘 단독 내비게이션 금지 — 항상 한글 라벨 병행.
- 의미색 규칙: 아이콘이 의미(정답/경고)를 전달하면 §11.2.4 색+라벨 동반.

### 11.5.2 일러스트 톤
- 반평면(semi-flat) + 부드러운 그라데이션, 골드 포인트. 사실적 3D·과장된 캐릭터 배제(교회 정서, 세속 게임 이미지 회피).
- **인물·직분 형상 금지**(제자·목회자·특정 성경 인물 도해 회피 → 교단·직분 민감성). 성경 속 **사물·자연물**만.

### 11.5.3 티어 상징 6종 비주얼 컨셉
공통 규격: 지름 비율 1:1 **원형 메달 프레임**, 중앙 심볼, 프레임 금속색으로 상승감, 배경 틴트로 단계 구분. 각 티어는 앞 단계보다 시각 밀도·광채가 커진다. 인물·왕권·직분 상징 배제.

| # | 티어 | 심볼 컨셉 | 프레임/색 | 배경 틴트 | 승급 연출 포인트 |
|---|---|---|---|---|---|
| 1 | 겨자씨 | 흙 위 작은 새싹(마 13:31) | 브론즈/흙빛 | 소프트 그린 | 겸손한 시작, 최소 광채 |
| 2 | 등불 | 기름등잔 + 따뜻한 불꽃(시 119:105) | 브라스 | 앰버 글로우 | 불꽃 점등 애니메이션 |
| 3 | 감람나무 | 뿌리내린 감람나무 + 골드 열매 | 브론즈-그린 | 딥 그린 | 잎사귀 흔들림 |
| 4 | 나팔 | 뿔나팔(쇼파르), 골드 | 골드 | 웜 골드 | 소리선(파동) 라인 |
| 5 | 방패 | 방패 + 무직분 엠블럼(십자·문양 배제) | 실버 + 골드 트림 | 스틸 블루 | 광택 스윕 |
| 6 | 면류관 | **월계관(승리자의 관, 딤후 4:8)** + 광선 | 래디언트 골드 | 밝은 골드 | 최대 광채·빛 방사 |

> **branding 검토 필요:** 6번 "면류관"을 **월계관(승리)** vs **왕관(왕권)** 중 무엇으로 형상화할지. 왕관은 직분·군주 이미지로 교회 정서상 민감 → **월계관 권고**. (openQuestions)

**의존: branding** 아트 디렉션 최종 승인 + 필요 시 외주 일러스트레이터 예산. 스케일: SVG 벡터 원본 → 프로필 64/128, 리스트 배지 32, 공유카드 480px 내보내기.

## 11.6 컴포넌트 라이브러리

모든 컴포넌트는 5상태(default/pressed/disabled/focus/loading)와 라이트·다크 대응을 갖는다.

### 11.6.1 버튼
| 종류 | 스펙 | 사용 |
|---|---|---|
| Primary | `primary` 채움, `onPrimary` 텍스트, 높이 56, 반경 12, Button 20 Bold, 전폭 | 화면당 1개 주행동(`퀴즈 시작`, `정답 확인`, `다음`) |
| Secondary | 표면 채움 + `primary` 2dp 테두리·텍스트, 높이 56 | 보조 행동(`건너뛰기`) |
| Tertiary(Text) | 텍스트 링크형, 탭영역 48 | 저위계(`나중에`) |
| Destructive | `error` 테두리·텍스트(채움 아님), 확인 모달 필수 | 교회 변경·구독 취소·탈퇴 |
| Reward Ad | Secondary + ▶ 아이콘, "광고 보고 2배" — **골드 금지**(수익 오인 방지), `primary` 계열 | 보상형 광고 진입 |
| Icon | 아이콘 28 + 탭 48, 라벨 툴팁 | 보조 액션 |

주행동 버튼은 항상 화면 하단 고정(thumb zone) + safe-area 패딩.

### 11.6.2 선택지 버튼 (Choice) — 퀴즈 핵심
- 전폭, 높이 64, 반경 12, 텍스트 Choice 20 SemiBold 좌측 정렬, 세로 12 간격 4개.
- **응답 방식(기본) = 선택 후 [정답 확인] 제출.** 중장년 오터치 방지(§11.1.3) 원칙에 따라 탭 즉시 확정하지 않고, 선택은 중립 표시 → 하단 **[정답 확인]** 으로 제출한다. 설정 "빠른 응답" 토글 시 선택 즉시 제출(오터치 감수). PRD F1 "즉시채점"은 **문항별 즉시(제출 시점) 채점**을 뜻하며 확인 스텝과 무모순.
- 상태: `default`(surface + border) → `selected`(primaryContainer 테두리 강조, **중립·미채점**, 프레스 햅틱 light) → 제출 → **서버 채점 응답 후**: 선택+정답 = `success` 채움 + ✓, 선택+오답 = **무채색 처리**(§11.2.4) + ✕ **및 정답 선택지 `success` 강조**, 미선택지 = 흐림(opacity 0.5, 텍스트 대비 유지).
- **정오는 서버 응답 후에만 확정·표시.** 온라인 기본모드 안티치트는 정답키를 클라에 내리지 않으므로 로컬 즉시 채점을 가정하지 않는다. 제출~응답 사이는 **마이크로 스피너 ≤300ms / 스켈레톤**으로 흡수(진행 차단 금지). 응답 후 정오 햅틱(정답 light / 오답 medium)·색·근거구절을 노출. 채점 후 전체 비활성, `다음` 노출.
- **낙관적 UI는 포인트·리더보드 표시에만 적용, 퀴즈 정오에는 미적용.** 약전파 시 스피너로 지연 흡수, 오프라인(로컬키 없음)에선 "네트워크 확인" 인라인 후 재시도.
- **안티치트 latency**는 **문제 렌더 시점~[정답 확인] 제출 시점** 기준으로 측정(1.5초 룰). "빠른 응답" 모드에선 렌더~선택 탭 기준.
- **의존: content** 선택지 최대 글자수(권고 40자 이내, 2줄 초과 시 자동 확장 높이). **client** 서버 왕복 채점·스피너·"빠른 응답" 토글. **server** 정오 응답 p95 예산(스피너 300ms 흡수 가능하도록).

### 11.6.3 카드
| 카드 | 구성 |
|---|---|
| 오늘의 말씀 | 구절 본문(Question 22) + 출처 + **번역본/판권 표기 슬롯**(개역개정, §11.8·legal) |
| 통계/요약 카드 | 큰 숫자(Display) + 라벨 + 변동 인디케이터 |
| 티어 카드(프로필) | 티어 심볼 128 + 티어명 + 다음 티어까지 진행바 |
| 결과 요약 카드(20문제) | 정답수/획득pt/콤보 + `계속` (직후 전면광고 트리거 지점) |
| 리스트 카드(교회/설정) | 좌 아이콘/배지 + 제목/보조 + 우 액션(> 또는 값) |

### 11.6.4 리스트 행 (리더보드·기여자)
`[순위 or 메달] [티어 배지 32] [이름 H3] [보조: 상위%] ...... [점수 tnum 우측정렬]`, 행 높이 64. 상위 1~3위는 메달 색(골드/실버/브론즈, 색+숫자 병기). "내 행"은 `primaryContainer` 배경 + 상단 sticky 고정.

### 11.6.5 탭
- **하단 내비 3개**(홈·순위·내정보), 아이콘 28 + 라벨 15 **항상 표시**, 활성=`primary` + Bold, 비활성=`textMuted`. 높이 64+safe area. **4개 이상 절대 금지**(PRD 하드 제약).
- 상단 세그먼트 컨트롤(전국/시도/우리교회 3탭, 규모 리그): 높이 48, 활성=`primary` 밑줄+Bold. 4개 초과 시 스크롤 대신 드롭다운.

### 11.6.6 모달·시트
- **바텀시트 우선**(엄지 도달성). 중앙 다이얼로그는 파괴적 확인에만.
- 승급·첫 티어 = **풀스크린 셀러브레이션**(축하카드 미리보기 + 공유 1탭 + 닫기). 자동 닫힘 금지, `닫기` 항상 크게.
- 시트 상단 반경 24, 드래그 핸들, 최상단 `닫기`(48) — 중장년은 스와이프 다운을 놓칠 수 있어 명시 버튼 필수.

### 11.6.7 토스트/스낵바
- 하단 고정, 3초 노출 + `확인`. 필수 정보(신고 접수)는 토스트가 아닌 인라인 확인.
- 색: 정보=`primary`, 성공=`success`, 오류=`error`, 각기 아이콘 동반. 상단 알림 배너는 푸시 인앱 표시에만.

### 11.6.8 입력·기타
- 교회 검색: 대형 검색창(높이 56) + 실시간 후보 리스트(지역 표기 강조) + "직접 등록" 폴백 버튼 상시.
- 초대 코드 입력: 6자리 개별 셀(각 48×56, 숫자 키패드), 붙여넣기 지원.
- 카테고리 칩: pill, 높이 44, 선택=`primaryContainer`+`primary` 텍스트.
- 진행바: 20문제 진행(1/20~20/20) + 콤보 표시(연속 n, 5·10 임계 도달 시 골드 펄스 1회).
- 배지: §11.10.
- 광고 컨테이너: 배너=고정 높이 예약(레이아웃 시프트 방지), **퀴즈 화면 배너 금지**(오터치), 리더보드·통계 하단만. **의존: monetization** SDK 렌더 규격.

## 11.7 화면별 레이아웃 원칙

공통: 상단 안전영역 + 화면 제목(H1), 좌우 20 gutter, 주 CTA 하단 고정.

### 11.7.1 홈 (탭1)
```
[오늘의 말씀 카드]  (구절 + 출처 + 판권 슬롯: 개역개정)
[출석 체크 스트립]  (연속 n일 + 오늘 체크)
[ 퀴즈 시작 ]        ← 대형 Primary(높이 64), 화면 최상 위계
[우리 교회 순위 요약] (순위·변동·기여 미리보기 → 탭 시 교회상세)
[교회 미등록 배너]    (미등록 시에만, "우리 교회 등록하기")
```
원칙: 스크롤 없이 `퀴즈 시작` 노출. 광고 없음.

### 11.7.2 퀴즈 (홈에서 진입, 풀스크린)
```
[상단: 진행 1/20 · 카테고리 칩 · 콤보]   (뒤로=종료 확인)
[문제 지문 카드 — Question 22, 넉넉한 여백]
[선택지 A]  [B]  [C]  [D]   (각 64, 세로 12 간격 — 선택 시 중립 표시)
[ 정답 확인 ]  (하단 고정 Primary; 설정 "빠른 응답" 시 선택 즉시 제출)
── 서버 채점 응답 후(제출~응답 ≤300ms 스피너/스켈레톤 흡수) ──
[정답/오답 인라인 + 근거구절(판권/폴백 슬롯: 미확보 시 장·절만) + 🚩오류 신고]
[ 다음 ]  (하단 고정 Primary)
```
원칙: 배너·불필요 chrome 제거. 정오·근거구절은 **서버 응답 후 표시**(로컬 즉시 채점 미가정). 20문제 결과 요약 카드 → 직후 전면광고(결과 확인 후 노출, 문제 도중 금지).

### 11.7.3 리더보드 (탭2)
```
[세그먼트: 전국 | 시도 | 우리 교회]
[내 순위 카드 — sticky 상단 고정, "전국 1,204위 · 상위 8%"]
[교회 대항 섹션: 규모 리그 선택(개척/중형/대형) + 우리 교회 순위]
[개인 랭킹 리스트(주간 기본 / 누적 토글)]
[하단 배너 광고 슬롯]
```

### 11.7.4 교회 상세
```
[헤더: 교회명 · "N명의 성도" · 이번 주 순위 · 규모 리그]
[순위 추이 미니 차트]     (data 스키마 의존)
[ 우리 교회 응원하기 ]    ← 공유 1탭(교회 성적표 카드)
[이번 주 기여자 TOP 20]  (티어 배지 + 이름 + 기여pt)
[탭: 이번 달 초대왕]      (v1.1)
```
교회 정체성(이름·인원)을 개인보다 크게. 교회명은 민감정보(종교) — 공개 노출 동의 연동(**legal**).

### 11.7.5 프로필 (탭3, 내정보)
```
[티어 카드: 심볼 128 + 티어명 + 다음 티어 진행바]
[배지 그리드]            (획득/미획득/진행)
[통계: 총 풀이·정답률·연속출석]
[오답노트]  (구독 미가입 시 제한 + 프리미엄 유도)
[프리미엄 배너]  (골드 금지, primary 톤)
[문의하기(CS) · 설정]   ← ops CS 진입점
```

### 11.7.6 온보딩 (풀스크린 단계, 이탈 최소화)
```
1) 카카오 로그인(+Apple)      ← 단일 대형 버튼
2) 글자 크기 선택            ← "보통 / 크게(권장) / 아주 크게" 3단계 실사이즈 미리보기(§11.3.3)
3) 난이도 진단 10문제         ← 광고 없음, 즉시 재미
4) 첫 티어 부여 연출(겨자씨)  ← 셀러브레이션 + 공유 유도
5) 교회 등록 유도            ← 스킵 가능(홈 배너 재유도)
── 각 단계 사이 삽입(법무, server가 내리는 동의 목록 기반) ──
[민감정보(종교) 처리 동의] · [B2B/목회자 제공(목적외) 별도 선택 동의(거부해도 이용 가능)]
[만14세 연령 확인/법정대리인] · [ATT/국외이전 사전 안내]
```
원칙: 단계별 1행동 1화면, 진행 인디케이터(●○○○○), 뒤로가기 허용. 동의 화면은 **데이터 기반**(server 제공 목록, client 13.10)으로 렌더하여 legal/monetization/data가 요구하는 항목 누락을 차단. **의존: legal**(동의 화면 카피·순서), **ux**(플로우), **data**(온보딩 퍼널 이벤트), **server**(동의 목록).

## 11.8 법무·수익화 요구 UI 표면 (갭 해소)

디자인이 자리를 만들어야 위법·심사 리스크가 해소된다. 카피는 legal, 데이터는 server 제공.

> **라이선스 게이트 범위(통일):** 성경 verbatim 노출은 **오늘의 말씀 + F1 근거구절 + F9 원문 축자** 전체가 대한성서공회 등 저작권 보호 대상이다. "퀴즈는 라이선스 불필요"라는 인식을 폐기하고, 아래 판권/폴백 슬롯을 **오늘의 말씀 카드뿐 아니라 퀴즈 근거구절·원문 화면에도** 둔다. 번역본은 **개역개정으로 통일**(개역한글도 성서공회 보호 저작물이므로 폴백 아님; 퀴즈 표기와 일원화, content §18.8 원칙과 정합).

## 11.9 공유 이미지 템플릿 (카톡 최적화)

바이럴 루프의 핵심. 모든 공유는 **1탭**, 카드는 서버 렌더 or 클라 캔버스로 생성.

### 11.9.1 규격 결정
| 채널/용도 | 비율·해상도 | 근거 |
|---|---|---|
| 채팅방 이미지 카드(주력) | **4:5 세로, 1080×1350** | 카톡 채팅방에서 세로형이 화면 점유·주목도 최대, 구역방 공유 최적 |
| 카카오링크 피드 썸네일 | **2:1, 800×400** | 링크 미리보기 규격, 큰 텍스트 1줄 |
| 정사각 폴백 | 1:1, 1080×1080 | 인스타·밴드 병행 |

세이프존: 상하좌우 각 80px 텍스트 배치 금지 영역. 최소 텍스트 = 카드 폭의 4% (썸네일에서도 판독). 브랜드 락업(로고+워드마크) 하단 고정.

### 11.9.2 3종 템플릿
| 템플릿 | 핵심 요소 | CTA |
|---|---|---|
| **승급 축하카드** | 티어 심볼 대형(480) + "○○님, **면류관** 달성!" + 골드 광채 배경 | "나도 도전하기" 딥링크 |
| **주간 결산 카드** | "지난주 **우리 교회** 성적표" + 순위·변동(▲) + 기여자 상위 + 규모 리그 | "우리 교회 응원하기" |
| **교회 성적표/응원** | "우리 교회 전국 **12위**!" + 규모 리그 뱃지 + 성도 수 | "우리 교회에 힘 보태기" |

### 11.9.3 프라이버시 규칙 (민감정보 주의)
- 공유 카드의 **교회명 = 종교 관련 민감정보** → 사용자 명시 동의 없이 자동 노출 금지, 공유 전 **이름/교회명 표시 여부 토글** 제공.
- 미성년·닉네임 사용자는 실명 대신 닉네임/이니셜만.
- 딥링크 파라미터(초대 자동귀속·UTM) 표면은 **data/marketing**과 규약.

**의존: marketing**(UA 크리에이티브 파생·카카오링크 템플릿), **data**(딥링크/UTM), **server**(카드용 순위·기여 데이터), **legal**(동의·판권).

## 11.10 배지 시스템 비주얼

공통 언어: **원형 메달리온**, 카테고리별 프레임 색, 미획득=그레이스케일+자물쇠, 진행형=원형 프로그레스 링. 프로필 그리드 4열, 탭 시 상세 시트(획득 조건·일자).

| 배지군 | 항목 | 프레임 색 | 상태 |
|---|---|---|---|
| 티어(6) | 겨자씨~면류관 | 골드 계열 상승 | 획득/현재/다음(진행바) |
| 출석 | 7·30·100일 연속 | 그린 | 진행 링(연속일) |
| 오류신고 | 파수꾼(3)·성경 지킴이(10) | 블루 | 마일스톤 진행 |
| 초대 | 동역자(10)·부흥의 손(30) | 골드 | 누적 진행(v1.1) |
| 초대왕 | 이번 달 교회 초대왕 | 골드+월계 | 월간 획득(v1.1) |

| 항목 | 규칙 |


### 11.13.2 토큰 구조 (2계층)
**Primitive → Semantic** 2단 매핑. 브랜딩 확정 시 Primitive만 교체.
- Primitive 예: `blue.700=#1D4E89`, `gold.500=#C68A2E`, `gray.900=#1A1A1A`
- Semantic 예: `color.primary → blue.700`, `color.textPrimary → gray.900`, `color.honor → gold.500`
- **배율 토큰:** `scale.app = {보통 1.0, 크게 1.15, 아주큰 1.3}`, `scale.clampMax = 1.6`(§11.3.3 단일값) — client·qa 공통 참조.
- 모드: `light` / `dark` 컬렉션으로 Semantic 값만 분기.
- 명명: Material 3 정합(`primary/onPrimary/surface/onSurface/error/outline`)으로 Flutter `ColorScheme` 직결.

### 11.13.3 Flutter 핸드오프
- 토큰을 **W3C Design Tokens JSON**으로 내보내 `ThemeData`/`ColorScheme`·`TextTheme` 생성(Style Dictionary 또는 수동 매핑 파일 1개).
- 컴포넌트는 Material 3 위젯 커스텀 테마로 매핑(`FilledButton`=Primary, `Card`, `NavigationBar`=하단탭 3, `BottomSheet`).
- 에셋: 티어/배지 = SVG(flutter_svg) 벡터, 공유카드 배경 = 3x PNG. 아이콘 = Material Symbols 폰트 서브셋.

### 11.13.4 핸드오프 체크리스트 (client·qa 공통 검수)
- [ ] 모든 텍스트 토큰이 대비 목표(§11.2.2) 통과(자동 검사 CI 게이트)
