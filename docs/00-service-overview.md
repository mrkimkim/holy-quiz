# 00. 서비스 이해 — 우리가 만들려는 것

> **한 줄 목적**: 중장년 기독교인이 매일의 신앙 습관에 얹어 성경 퀴즈를 풀고, 개인의 명예 티어와 '우리 교회'의 리더보드 순위를 위해 겨루게 만드는 — 그래서 권사님 한 분의 자부심이 구역 카톡방을 타고 마케팅 예산을 대체하는 — 교회 대항 성경 퀴즈 게임.

---

## 1) 엘리베이터 피치

한국 개신교 770만 명, 그 절반 이상이 45세 이상입니다. 이들은 이미 매일 새벽기도와 QT라는 신앙 습관을 갖고 있고, 성경 지식에 자부심이 있으며, 무엇보다 '우리 교회'라는 강한 소속감으로 묶여 있습니다. **말씀퀴즈**는 이 세 가지 — 매일의 습관, 성경 지식의 자부심, 교회 소속감 — 을 하나의 모바일 게임 루프로 엮습니다. 사용자는 4지선다 성경 퀴즈를 무제한으로 풀며 포인트를 쌓아 '겨자씨→면류관'으로 이어지는 명예 티어를 올리고, 동시에 자신의 점수가 '우리 교회'의 주간 순위에 합산됩니다. 골프 단체전처럼 교회별 상위 20명의 점수가 합산되어 전국·규모별 리그에서 다른 교회와 겨루고, 순위가 오를 때마다 성도들은 그 성적표를 구역 카톡방에 자연스럽게 공유합니다. 현금성 보상은 일절 없고 오직 '명예'로만 경쟁하기에 사행성 논란을 피하고, 이 교회 단위 바이럴이 곧 유료 마케팅을 대체하는 성장엔진이 됩니다. 수익은 헤비 유저의 광고 노출을 주축으로, 광고를 거슬려하는 경쟁형 사용자의 소액 구독을 보조로 삼으며, 축적되는 교회 데이터베이스는 훗날 목회자 도구(B2B)로 확장됩니다.

## 2) 서비스의 본질과 정의

- **표면적으로는**: iOS/Android(Flutter) 모바일 성경 퀴즈 게임.
- **본질적으로는**: 세 가지를 결합한 **'교회 소속감 기반 소셜 학습 경쟁 플랫폼'**입니다.
  - **습관 도구** — 기존의 새벽기도/QT 루틴에 '한 판 더'로 얹히는 매일의 앵커(오늘의 말씀, 출석체크).
  - **명예 게임** — 환전·소비 불가능한 순수 명예 포인트/티어로만 작동하는, 사행성 없는 경쟁 시스템.
  - **교회 커뮤니티 성장기계** — 개인의 플레이가 '우리 교회'의 성적으로 환산되어, 오프라인 공동체가 온라인 바이럴 채널로 전환되는 구조.
- **정의를 가르는 결정적 경계선**:
  - 성경의 **'내용 이해'를 묻는다**. 자구 암송형·교리/해석형(세례 vs 침례, 종말론 등)은 **출제하지 않는다** → 교단 민감성 회피가 제품 정체성의 일부.
  - **'명예로만' 겨룬다**. 포인트는 돈으로도, 아이템으로도 바뀌지 않는다 → 사행성 차단이 제품 정체성의 일부.
  - **'교회가 팀'이다**. 개인전이 아니라 소속 단체전이 핵심이다 → 이것이 여느 성경 퀴즈 앱과 갈리는 지점.
- **무엇이 아닌가(Not)**: 성경 암송 앱이 아니고, 신학 교육 앱이 아니며, 현금 리워드 앱이 아니고, v1에서는 커뮤니티 게시판·사용자 출제·포인트 상점·다국어를 갖지 않는다.

## 3) 핵심 가치제안

**사용자 관점**
- **매일의 신앙 습관에 얹는 작은 성취**: 무제한 풀이 + 근거 구절 제공으로 '재미있게 성경을 다시 본다'는 감각. 틀려도 해설과 오답노트로 배움이 남는다.
- **평생 쌓이는 명예**: 하락 없는 누적 티어(겨자씨→면류관)와 배지가 '성경 지식 자부심'을 눈에 보이는 상징으로 인정해준다.
- **내가 우리 교회에 기여한다는 감각**: 내 점수가 교회 순위를 끌어올린다 → 개인 동기를 넘어 공동체 기여 동기로 확장.
- **부담 없는 접근성**: 큰 글씨, 카카오 단일 로그인, 최소 탭 깊이 — 40~70대가 도움 없이 쓸 수 있다.

**교회 관점**
- **성도의 신앙 활동을 가시화**: 우리 교회의 순위 추이, 참여 인원, 기여자 TOP20이 공동체의 활력 지표가 된다.
- **세대 통합의 매개**: 청년부 리더/전도사가 캠페인으로 권사·집사 세대를 디지털로 끌어들이는 브릿지가 된다.
- **비용 없는 결속 이벤트**: 교회 대항전과 주간 성적표가 별도 예산·행사 없이 성도 간 결속과 대화 소재를 만든다.
- **(장기) 목회 도구**: 축적된 데이터가 목회자 대시보드(v2.0)로 이어져 성경 학습 현황을 지원한다.

## 4) 타깃 (P1 / P2 / P3)

| | P1 김순자 (62·권사) | P2 박성호 (47·안수집사) | P3 이하은 (34·청년부리더/전도사) |
|---|---|---|---|
| **역할** | 핵심 사용자 · 바이럴 전파원 | 수익 기여자 | 전파자 · 유입 브릿지 |
| **행동** | 카톡·유튜브·밴드 / 새벽기도 후·저녁 / 구역모임 전파 | 출퇴근 지하철 / 강한 경쟁심 / 티어 승급 몰입 | 교회 디지털 채널 보유 / 캠페인 운영 |
| **결제** | 거의 안 함, 그러나 광고엔 관대 | 광고 거슬리면 기꺼이 구독 | (전파 역할, 결제 아님) |
| **이탈 트리거** | 작은 글씨·복잡한 메뉴 → 즉시 이탈 | 광고 피로 | — |

**각자에게 주는 가치**
- **P1에게**: '나는 성경을 잘 안다'는 자부심을 티어·배지로 인정받고, 그 성취를 구역 카톡방에 자랑하는 즐거움 → **명예와 사회적 인정**. (제품의 접근성 설계가 P1을 위해 존재한다.)
- **P2에게**: 티어 승급과 순위 경쟁의 몰입, 그리고 방해받지 않고 몰입하기 위한 광고 제거 구독 → **경쟁과 몰입**. (제품의 수익이 P2에게서 나온다.)
- **P3에게**: 교회 캠페인 도구로 활용해 성도 참여를 끌어올리고 세대 통합을 실현 → **공동체 도구**. (제품의 확산 스위치가 P3의 손에 있다.)

> 세 페르소나는 각각 **성장(P1)·수익(P2)·확산(P3)** 이라는 서로 다른 엔진을 담당하며, 셋이 맞물릴 때 비로소 자기증식 루프가 완성된다.

## 5) 핵심 경험 루프 (텍스트 다이어그램)

```
        ┌────────────────────────────────────────────────────────┐
        │                                                        │
        ▼                                                        │
 [진입] 오늘의 말씀 · 출석체크 (매일의 앵커)                       │
        │                                                        │
        ▼                                                        │
 [퀴즈] 4지선다 무제한 풀이 · 즉시 채점 · 근거구절/해설            │
        │  (콤보 5→+10% / 10→+25%, 20문제마다 전면광고)           │
        ▼                                                        │
 [포인트] 신규정답 10/15/25pt 획득 (재출제·매크로는 차감/무효)     │
        │                                                        │
        ▼                                                        │
 [티어] 누적 포인트로 승급 (겨자씨→…→면류관, 하락 없음)          │
        │  └──▶ 승급 축하카드 생성                                │
        ▼                                                        │
 [교회 리더보드] 내 주간 점수가 '우리 교회' 상위20 합산에 기여     │
        │  (전국/시도/우리교회 · 규모리그 · 순위 추이)            │
        ▼                                                        │
 [공유] 승급카드·주간 성적표를 1탭으로 구역 카톡방에 공유          │
        │                                                        │
        ▼                                                        │
 [재유입/신규유입]                                               │
   ├─ 기존 사용자: 푸시(순위변동/주간마감 D-1) → 다시 진입 ───────┘
   └─ 신규 사용자: 카톡 딥링크로 가입 → 교회등록 → 20문제 완료

```

- **개인 루프**(퀴즈→포인트→티어)는 하루 안의 리텐션을 만들고,
- **공동체 루프**(교회 리더보드→공유→재유입)는 주 단위 리텐션과 신규 유입을 만든다.
- 두 루프의 접합부가 **'내 점수 = 우리 교회 점수'** 라는 단일 환산 규칙이며, 이것이 개인 동기를 커뮤니티 성장으로 번역하는 심장이다.

## 6) 결정적 차별화 — 왜 교회 대항전이 성장엔진인가

기존 성경 퀴즈 앱은 '개인이 혼자 문제를 푸는' 완성도 낮은 도구에 머물렀다. 말씀퀴즈의 유일하고도 방어 가능한 차별점은 **점수를 개인이 아니라 이미 존재하는 오프라인 공동체(교회)에 귀속시킨다**는 설계다. 이것이 성장엔진인 이유:

1. **동기의 전환**: '내 점수'는 나만의 것이지만 '우리 교회 순위'는 자랑하고 공유할 명분이 된다. 개인 성취의 자랑은 눈치가 보여도, 공동체를 위한 기여는 떳떳하게 공유된다.
2. **공유의 목적지가 이미 존재한다**: 구역 카톡방·밴드라는 강결속 채널이 이미 매일 돌아가고 있다. 제품은 새 네트워크를 만들 필요 없이 **기존 네트워크에 콘텐츠(성적표)를 흘려보내기만** 하면 된다.
3. **사회적 압력의 선순환**: 상위 20명 합산(단체전) 구조라 "우리 교회 순위 떨어졌어요, 이번 주 좀 풀어요"라는 **동료 간 소환**이 자연 발생한다 — 이것이 리텐션과 재유입을 동시에 밀어올린다.
4. **마케팅 예산의 대체**: P1(권사) 한 명의 자부심이 구역 전체를 끌고 오면, CPI ₩3,000짜리 유료 유입보다 값싸고 신뢰도 높은 유입이 된다. 즉 **교회 대항전 = 무료·고신뢰 유통망**.
5. **공정성 장치가 신뢰를 지킨다**: 대형교회 인원 우위를 상위 N명 합산 + 규모 리그(개척/중형/대형)로 눌러, 작은 교회도 이길 수 있게 만든다 → 참여 동기가 상위 소수에 쏠리지 않고 폭넓게 유지된다.

## 7) 비즈니스 모델 한눈에

- **① 광고 (주 수익원)**: 전면광고를 20문제마다 1회(결과 요약 직후) 노출. 헤비 유저는 하루 5회 이상. 목표 ARPDAU ₩30+ (전면 2.5회/일 × eCPM ₩12,000). 보상형(선택, 다음 20문제 2배)과 배너(리더보드/통계 하단에만, 퀴즈 화면엔 미노출)로 보완. → **P1(광고에 관대)** 이 지탱.
- **② 구독 '말씀퀴즈 프리미엄' (보조 수익원)**: 월 ₩3,900 / 연 ₩29,000. 혜택은 광고 제거 + 오답노트 무제한 + 카테고리별 정답률 통계 + 후원자 배지. 전환율 목표 1.0%. → **P2(광고 거슬리면 결제)** 가 지탱. **철칙: 포인트·티어에 영향 주는 혜택은 절대 불포함**(공정성 = 명예 시스템의 신뢰 기반).
- **③ 교회 DB 자산화 → B2B 확장 (미래 성장축)**: 교회 등록·참여·기여 데이터가 축적되면 v2.0에서 목회자 대시보드(B2B)로 전환. 개인 대상 광고·구독 모델을 넘어서는 장기 해자.

> 구조 요약: **광고로 대중(P1)을 수익화하고, 구독으로 헤비 경쟁층(P2)을 수익화하며, 데이터로 교회(B2B)를 미래 수익화한다.** 목표는 12개월 내 MAU 10만, 월 매출 2,000만원+.

## 8) 제품을 관통하는 4대 설계철학의 의미 해석

1. **"매일의 습관에 얹는다"** — 새 습관을 만들지 않는다. 이미 성립된 새벽기도·QT 루틴 **옆에 붙는다**. → '오늘의 말씀'을 진입 첫 화면에 두고, 출석체크로 연속성을 보상한다. 습관을 창조하는 제품은 실패하지만, 습관에 기생하는 제품은 산다.
2. **"명예로 경쟁한다(현금성 보상 없음)"** — 경쟁의 연료를 돈이 아니라 명예로 삼아 **사행성을 원천 차단**한다. → 포인트 환전·소비 불가, 티어 하락 없음, 구독이 순위에 영향 없음. 이는 규제 리스크 회피이자, 종교 사용자층의 도덕적 수용성을 지키는 장치.
3. **"교회가 팀이다"** — 개인전이 아니라 **소속 단체전**이 제품의 중력 중심이다. → 모든 개인 행동이 교회 점수로 환산되고, 공유·초대·리텐션이 전부 교회를 매개로 설계된다. 차별화(§6)와 성장엔진이 여기서 나온다.
4. **"중장년이 기본값이다"** — 젊은 사용자를 위한 UI에 접근성을 '추가'하는 게 아니라, **40~70대가 도움 없이 쓰는 것이 디폴트**다. → 본문 최소 18pt·선택지 버튼 56pt+, 하단탭 3개 이내, 깊이 2단계 초과 금지, 카카오 단일 로그인. P1이 첫 화면에서 이탈하면 성장엔진 전체가 꺼지므로, 접근성은 '배려'가 아니라 '생존 조건'이다.

> 네 철학은 독립적이지 않다. **중장년이 기본값(4)이라야 P1이 남고 → P1이 습관에 얹어(1) 매일 오며 → 명예 경쟁(2)으로 떳떳이 자랑하고 → 교회 팀(3)을 통해 그 자랑이 바이럴이 된다.** 하나라도 무너지면 루프가 끊긴다.

## 9) 성공의 조건과 실패의 조건

**성공의 조건 (반드시 참이어야 하는 것)**
- **핵심 가설 검증**: "교회 순위 상승 → 구역 카톡 공유"가 실제로 일어난다. 파일럿(협력교회 3~5곳)에서 이 공유 행동이 관측되어야 한다.
- **P1 온보딩 통과**: 40~70대가 도움 없이 진단 퀴즈·교회 등록까지 완주한다(온보딩 이탈 최소화).
- **콘텐츠 신뢰**: 신학 오류가 초기에 나오지 않고(사실기반+검수), 나오더라도 24h 내 신고·격리·수정으로 신뢰가 유지된다.
- **밸런스 방어**: 파밍/매크로가 명예 시스템의 변별력을 깨지 않는다(재출제 차감·연타 무효·이상탐지가 작동).
- **바이럴 임계치**: 유효초대 기반 K-factor 0.3+ 및 교회 등록률 60%+가 달성되어 자기증식이 시작된다.
- **리텐션 지표**: D1/D7/D30 = 45%/28%/18%, DAU/MAU 25%+가 나온다.

**실패의 조건 (하나라도 참이면 위험)**
- 점수가 개인에만 머물고 **교회 공유가 일어나지 않는다** → 성장엔진 부재, 유료 UA 의존으로 전락.
- **P1이 첫 화면에서 이탈**한다(글씨·메뉴 복잡) → 대중 기반과 바이럴 원천 동시 상실.
- **신학 오류·교단 민감 이슈**가 터지고 대응이 늦다 → 신뢰 붕괴, 교회 단위 이탈(공동체 단위라 이탈도 단위로 일어남).
- **파밍/매크로로 순위가 오염**된다 → 명예의 가치 하락 → 경쟁 동기(그리고 P2의 결제 동기) 소멸.
- **대형교회 편중**으로 작은 교회가 이길 수 없다 → 참여 저변 붕괴(규모 리그·상위 N 합산 장치 실패 시).
- **콘텐츠 조기 소진**(3,000문항을 헤비 유저가 빠르게 소진) → 월 500+ 증분과 재출제 차감이 못 따라가면 이탈.
