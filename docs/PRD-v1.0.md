## 1. 개요

### 1.1 한 줄 정의

성경 퀴즈를 무제한으로 풀며 포인트를 쌓고, 개인 티어와 **교회 대항 리더보드**에서 신앙 지식을 겨루는 중장년 기독교인 대상 모바일 퀴즈 게임.

### 1.2 배경과 기회

한국 개신교 인구는 약 770만 명이며 그중 45세 이상이 과반을 차지한다. 이 세대는 (1) 새벽기도·QT 등 매일 반복하는 신앙 습관이 이미 형성되어 있고, (2) 교회 성경퀴즈대회 문화를 통해 성경 지식 경쟁에 익숙하며, (3) 교회 공동체에 대한 소속감과 자부심이 강하다. 그러나 기존 성경 퀴즈 앱 시장은 개인 개발자 수준의 완성도이거나 번역투의 해외 앱뿐으로, **포인트 경제·티어·소셜 경쟁을 제대로 결합한 국산 앱이 부재**하다.

핵심 차별화는 **교회 단위 대항전**이다. 개인의 성경 지식 경쟁을 "우리 교회의 명예"로 확장하면, 이 세대의 소속감·경쟁심을 동시에 자극하고 구역 카톡방을 통한 유기적 확산(권사님 바이럴)이 유료 마케팅을 대체하는 성장 엔진이 된다.

### 1.3 제품 원칙

1. **매일의 습관에 얹는다** — 새로운 습관을 만들지 않고, 새벽기도·출퇴근·취침 전 루틴에 스며든다.
2. **명예로 경쟁한다** — 포인트는 현금성 보상이 아닌 순수 명예(티어·랭킹)다. 사행성 논란과 교회 정서 마찰을 원천 차단한다.
3. **교회가 팀이다** — 개인의 성취가 교회의 순위로 연결된다. 혼자 하는 앱이 아니라 "우리 교회를 위해" 하는 앱이다.
4. **중장년이 기본값이다** — 큰 글씨, 단순한 화면 구조, 최소한의 탭 깊이. 40~70대가 도움 없이 쓸 수 있어야 한다.

## 3. 타깃 사용자

### 3.1 페르소나

**P1. 김순자 (62세, 권사) — 핵심 사용자**
30년 신앙 생활. 스마트폰은 카톡·유튜브·밴드 위주로 사용. 새벽기도 후와 저녁 시간에 여유가 있다. 성경 지식에 자부심이 있고, 구역 모임에서 앱을 알게 되면 주변에 적극적으로 전파한다. 작은 글씨와 복잡한 메뉴에 즉시 이탈한다. 결제는 거의 하지 않지만 광고 시청에는 관대하다.

**P2. 박성호 (47세, 안수집사) — 수익 기여 사용자**
직장인, 출퇴근 지하철에서 사용. 경쟁심이 강해 개인 랭킹과 티어 승급에 몰입한다. 교회 리더보드에서 자기 기여도가 보이는 것을 즐긴다. 광고가 거슬리면 월 구독을 결제할 의사와 능력이 있다.

**P3. 이하은 (34세, 청년부 리더/전도사) — 전파자**
직접적 타깃은 아니지만 교회 내 디지털 채널(주보, 단체방)을 쥐고 있다. "다음 주까지 우리 교회 순위 올리기" 같은 캠페인을 만들어 P1·P2를 유입시키는 브릿지 역할.

### 3.2 핵심 사용자 시나리오

1. 김순자 권사는 새벽기도를 다녀와 아침 식사 후 앱을 연다. 출석 체크와 함께 오늘의 말씀 한 구절을 읽고 퀴즈를 시작한다. 40문제쯤 풀다가 광고를 두 번 보고, 어제보다 오른 교회 순위를 확인한 뒤 구역 카톡방에 "우리 교회 12위 됐어요!"를 공유한다.
2. 박성호 집사는 퇴근 지하철에서 연속 정답 콤보로 포인트를 쌓다가 "면류관" 티어 승급 알림을 받는다. 승급 카드를 캡처해 프로필에 자랑하고, 광고가 흐름을 끊자 월 구독을 결제한다.
3. 이하은 전도사는 교회가 아직 미등록인 것을 발견하고 교회 검색으로 등록한 뒤, 청년부 단체방에 초대 링크를 뿌린다. 그 주에 교인 30명이 가입한다.

## 4. 기능 요구사항

### F1. 퀴즈 플레이 (Core Loop)

| 항목 | 요구사항 |
|---|---|
| 플레이 방식 | **무제한 풀이.** 세션·하트 제한 없음. 언제든 시작하고 언제든 종료 |
| 문제 형식 | **4지선다 단일 형식.** 찍기 기대값 25%가 명예 시스템(티어·리더보드)의 변별력을 지키는 기본 조건. 보조 형식(스피드 OX 모드, 사실 빈칸)은 v1.1에서 추가 |
| 문제 구성 | 1문제 1화면, 즉시 채점, 정답 시 근거 구절 표기 (예: "창세기 12:1") |
| 광고 | **20문제마다 전면광고 1회.** 문제 도중이 아닌 20문제 단위 결과 요약 화면 직후에 노출 |
| 카테고리 | 구약 / 신약 / 인물 / 사건·지명 / 통합 랜덤 |
| 난이도 | 쉬움·보통·어려움. 온보딩 첫 10문제 결과로 초기 난이도 자동 배정 |
| 콤보 | 연속 정답 시 포인트 보너스 (5연속 +10%, 10연속 +25%). 세션 몰입도와 체류시간 견인 |
| 오답 처리 | 오답 시 포인트 0, 정답 해설 노출. 오답 문제는 오답노트에 자동 저장 (구독 기능과 연계) |

**포인트 획득 규칙 (파밍 방지 설계).** 무제한 풀이 구조에서는 같은 쉬운 문제를 반복해 포인트를 채굴하는 행위가 리더보드 신뢰를 무너뜨린다. 이를 다음 규칙으로 방어한다:

- 신규 문제 정답: 난이도별 10/15/25pt
- 과거에 맞힌 문제 재출제 시: 20% 포인트 (복습 가치는 인정하되 파밍 무력화)
- 문제은행 로테이션: 개인별 최근 정답 문제는 출제 우선순위 하향
- 비정상 속도 감지: 문제당 1.5초 미만 연타 반복 시 해당 세션 포인트 무효 (매크로 방어) — 스피드 OX 모드에는 미적용 (형식 특성상 속도 기준으로 봇을 구분할 수 없음)

**스피드 OX 모드 (v1.1, 보조 모드).** 출퇴근·대기 시간 같은 1~3분 초단기 세션을 위한 별도 모드. OX는 찍기 기대값이 50%라 정규 리더보드의 변별력을 해치므로, 문제당 포인트를 정규 4지선다의 1/3로 책정해 리더보드 오염 없이 가벼운 재미와 추가 광고 슬롯만 확보한다. 속도 기반 매크로 감지가 통하지 않는 형식이므로 대신 **일일 획득 포인트 상한**(정규 문제 30문제 분량)으로 어뷰징을 차단한다. 광고 규칙(20문제당 전면 1회)은 동일 적용.

### F2. 포인트·티어 시스템

포인트는 **환전·소비 불가, 순수 명예 전용**이다. 누적 포인트로 티어가 결정되며 티어는 하락하지 않는다 (중장년 사용자에게 강등의 상실감은 이탈 요인).

| 티어 | 누적 포인트 | 상징 |
|---|---|---|
| 1. 겨자씨 | 0 | 시작 (마 13:31) |
| 2. 등불 | 3,000 | 말씀을 밝히다 (시 119:105) |
| 3. 감람나무 | 10,000 | 뿌리내린 신앙 |
| 4. 나팔 | 30,000 | 지식을 전하다 |
| 5. 방패 | 80,000 | 믿음의 방패 (엡 6:16) |
| 6. 면류관 | 200,000 | 최고 명예 (딤후 4:8) |

- 티어 승급 시 전면 축하 카드 + 이미지 공유 기능 (카톡 공유 = 유입 루프)
- 티어 상징은 특정 인물·직분(제자, 사도 등)을 피하고 성경 속 사물로 구성해 교단·직분 민감성을 제거
- 티어별 프로필 배지, 교회 리더보드 내 기여자 목록에 배지 노출

### F3. 리더보드

**개인 리더보드**

- 전국 / 시도 / 우리 교회 내부 3개 탭
- 주간 랭킹 기본 (매주 월요일 00시 리셋) + 누적 랭킹 보조. 주간 리셋은 후발 주자에게도 매주 기회를 주어 상위권 고착을 방지
- 내 순위는 항상 상단 고정 노출 ("전국 1,204위 · 상위 8%")

**교회 대항 리더보드 (핵심 차별화)**

- 교회 점수 = **해당 주 우리 교회 상위 20명의 주간 포인트 합산.** 골프 단체전 방식으로, 대형교회의 인원수 우위를 제한하면서도 "내가 상위 20명에 들어 교회에 기여한다"는 동기를 만든다
- 규모 리그 분리: 주간 활동 인원 기준 개척(1~9명) / 중형(10~49명) / 대형(50명+) 리그로 나누어 각 리그별 순위 제공. 전체 통합 순위는 참고 지표로 병행 노출
- 교회 상세 페이지: 순위 추이, 이번 주 기여자 TOP 20, 참여 인원, "우리 교회 응원하기" 공유 버튼
- 부정 방지: F1의 파밍·매크로 방어 규칙이 교회 점수에도 동일 적용. 이상 패턴 교회는 운영자 검토 큐로

### F4. 교회 검색·등록

- 가입 후 온보딩에서 교회 등록 유도 (스킵 가능, 홈에서 상시 배너로 재유도)
- 장소 검색 기반 교회 찾기: 교회명 입력 → 지역·주소가 함께 표시된 후보 목록 → 선택. 동명 교회는 "서울 서초구" 같은 지역 표기로 구분
- 이미 등록된 교회는 "N명의 성도가 함께하고 있어요" 표시 (사회적 증거 → 등록 전환율 견인)
- 검색에 없는 개척교회는 직접 등록 폴백 제공 (운영 검수 큐로 유입)
- 교회 변경은 월 1회로 제한 (대항전 시즌 중 팀 갈아타기 방지)
- 사전 시딩: 리더보드 초기 신뢰를 위해 주요 대형교회 500~1,000개는 검증(verified) 상태로 사전 등록

### F5. 수익화

**광고 (주 수익원)**

- 전면광고: 20문제 결과 화면 직후. 무제한 풀이 구조상 헤비 유저는 일 5회+ 노출
- 보상형 광고 (선택): "광고 보고 다음 20문제 포인트 2배." 강제가 아닌 선택형으로 광고 인벤토리를 추가 확보. 포인트가 명예 전용이므로 현금성 pay-to-win 논란 없음
- 배너: 퀴즈 화면에는 미노출 (중장년 오터치 방지). 리더보드·통계 화면 하단만

**구독 — "말씀퀴즈 프리미엄" (보조 수익원)**

- 가격: 월 ₩3,900 / 연 ₩29,000
- 혜택: ① 모든 광고 제거 ② 오답노트 무제한 + 카테고리별 정답률 통계 ③ 프로필 후원자 배지 (리더보드 노출)
- 원칙: 포인트·티어에 영향을 주는 혜택은 절대 불포함 (경쟁 공정성 유지). "공부 도구 + 후원" 프레임으로 판매

### F6. 온보딩·접근성 (중장년 최적화)

- 로그인: 카카오 로그인 단일 (이 세대의 사실상 유일한 간편 인증). Apple 심사 요건상 Apple 로그인 병행
- 첫 실행: 큰 글씨 모드 선택 → 난이도 진단 10문제 (광고 없음) → 첫 티어 부여 연출 → 교회 등록 유도
- 전역 큰 글씨 모드: 본문 최소 18pt, 선택지 버튼 높이 56pt+
- 화면 구조: 하단 탭 3개 이내 (홈·순위·내정보). 설정 외 깊이 2단계 초과 금지

### F7. 리텐션 장치

- 출석 체크: 연속 출석 배지 (7일·30일·100일) + 소량 포인트
- 오늘의 말씀: 앱 진입 첫 화면에 매일 한 구절 (QT 습관과 연결되는 정서적 앵커)
- 푸시: ① 교회 순위 변동 ("우리 교회가 8위로 올랐어요!") ② 연속 출석 리마인드 ③ 주간 리더보드 마감 D-1. 일 1회 초과 금지
- 주간 결산 카드: 월요일 아침 "지난주 우리 교회 성적표" — 공유 유도의 정기 트리거

### F8. 초대 시스템 (성장 엔진)

교회 대항전의 "한 명이라도 더 데려와야 우리 교회가 이긴다"는 구조를 개인 명예로 증폭시키는 기능. 별도의 성장 채널이 아니라 대항전의 연장으로 설계한다.

**초대 방식**

- 메인: 카톡 공유 딥링크. 초대받은 사람이 링크로 설치·가입하면 초대자에게 자동 귀속 (코드 입력 불필요)
- 폴백: 개인 초대 코드 6자리. 링크 유실·수동 전달 케이스 대응 (가입 시 "초대 코드가 있나요?" 입력란)
- 초대 화면: 내 초대 코드, 누적 초대 수, 유효 초대 진행 상황 (가입만 한 친구 / 활동을 시작한 친구 구분 표시)

**유효 초대 정의 (어뷰징 방어의 핵심)**

초대 실적으로 인정되는 조건: 피초대자가 ① 신규 가입 ② 교회 등록 ③ 퀴즈 20문제 이상 완료를 모두 충족. 단순 가입은 "대기 중"으로 표시만 하고 순위에 미반영. 추가 방어: 동일 기기 반복 가입 차단, 1인당 일일 유효 초대 인정 상한 5건, 이상 패턴(단기 대량 초대)은 운영 검토 큐로.

**초대왕 리더보드**

- 위치: 우리 교회 상세 페이지 내 "이번 달 초대왕" 탭. 월간 리셋 (주간은 표본이 적어 순위가 무의미)
- 보상: 명예 전용. 월간 교회 초대왕 배지, 누적 유효 초대 마일스톤 배지 (10명 "동역자" / 30명 "부흥의 손" 등). 포인트 지급은 없음 — 퀴즈 실력 랭킹과 초대 실적을 분리해 각 리더보드의 순수성 유지
- 명칭 후보: "초대왕" (안전) vs "전도왕" (문화적 울림이 크지만 기존 신자 초대를 전도로 부르는 데 이견 가능). 파일럿에서 반응 테스트

**초대 독려 팝업 (맥락 기반 원칙)**

콜드 팝업은 중장년 리텐션을 훼손하므로, 사용자가 공유 동기를 이미 가진 순간에만 노출한다:

| 트리거 | 메시지 예시 |
|---|---|
| 티어 승급 직후 | "면류관 달성! 이 기쁨을 교회 식구들과 나눠보세요" |
| 교회 순위 상승·근접 | "3명만 더 함께하면 우리 교회 10위 진입!" |
| 주간 결산 카드 | "지난주 우리 교회 성적표를 구역방에 공유해보세요" |
| 첫 티어 달성 (온보딩 종료) | "함께 풀면 우리 교회 순위가 올라가요" |

운영 규칙: 맥락 팝업 일 1회 상한, 트리거 없는 콜드 팝업은 주 1회 상한, 퀴즈 플레이 중 노출 절대 금지, "다시 보지 않기" 옵션 상시 제공.

### F9. 문제 오류 신고·자동 검증 시스템 (신뢰 인프라)

타깃 사용자층은 성경 관련 오류 하나에 앱 전체의 신뢰를 거두는 특성이 있다. 오류 신고는 단순 CS 기능이 아니라 **사용자를 품질 관리의 동역자로 만드는 참여 기능**이자, 성경 본문을 단일 기준(source of truth)으로 삼는 자동 유지보수 파이프라인의 입구다.

**신고 UX**

- 문제 해설 화면에 "오류 신고" 버튼 상시 노출
- 신고 사유는 원탭 선택: 정답이 틀림 / 근거 구절이 다름 / 오타·표기 / 문제가 모호함 / 기타(자유 입력). 중장년 사용자가 긴 글을 쓰지 않아도 신고할 수 있어야 한다
- 신고 접수 즉시 "확인 후 알려드리겠다"는 피드백 노출

**자동 격리 (즉시 방어)**

다음 조건 중 하나라도 충족하면 해당 문제를 출제 풀에서 자동 임시 제외:

- 동일 문제 신고 누적 3건
- 정답률 이상치 (출제 50회 이상 & 정답률 15% 미만 — 문제 자체가 틀렸을 확률이 높은 신호)
- 특정 오답 선택지로의 비정상 쏠림 (복수 정답 가능성 신호)

신고가 없어도 정답률 지표만으로 격리가 발동하므로, 신고 기능은 사후 방어가 아니라 이중 감시망이 된다.

**자동 검증·수리 파이프라인**

기준은 항상 성경 본문의 '내용'이다(자구 대조가 아님). 검증기의 질문은 하나다: **"이 문제가 진술하는 사실이 근거 구절의 내용과 일치하는가."** 모든 문제가 근거 구절을 필수로 갖는 출제 원칙(5장) 덕분에 이 기계 검증이 가능하다.

1. 격리된 문제 + 근거 구절 원문 + 신고 사유를 LLM 검증기에 입력
2. 검증기 판정: ① 문제 정상 (신고 기각) ② 오타·표기 오류 ③ 정답·내용 오류 ④ 판단 유보 — 각 판정에 신뢰도 점수와 수정안 첨부
3. 처리 분기:
   - **오타·표기 수준 → 자동 수정 후 즉시 복귀** (정답 불변 조건 하에서만)
   - **정답·내용 오류 → 수정안 자동 생성 후 검수자 승인 대기.** 정답이 바뀌는 수정의 무인 배포는 금지 — 검증기의 오판이 멀쩡한 문제를 틀리게 고치는 사고는 원래 오류보다 신뢰에 더 치명적이다
   - **판단 유보·저신뢰도 → 무조건 인간 검수**
   - 신고 기각 시 문제 자동 복귀, 기각 사유 로그 보존
4. SLA: 격리 즉시(자동), 자동 판정 24시간 내, 검수 승인 72시간 내

**신고자 보상 루프 (신뢰의 가시화)**

- 신고가 채택되어 문제가 수정되면 신고자에게 푸시: "회원님의 제보로 문제가 바로잡혔어요" + 소량 포인트
- 누적 채택 마일스톤 배지: 3건 "파수꾼", 10건 "성경 지킴이". 오류를 찾는 행위 자체를 명예로 전환
- 월간 운영 리포트(선택): "이번 달 N건의 제보로 문제 M개가 수정되었습니다" — 품질 관리가 작동하고 있음을 공개적으로 증명

**성경 본문 저작권**

퀴즈가 내용 이해형으로 한정되므로(5장 출제 철학) 번역문 자구를 재현하지 않아, **퀴즈·해설 자체에는 번역본 라이선스가 필요 없다** (성경 속 사실과 사건은 저작권 보호 대상이 아니며, 구절 주소 표기는 인용이 아님). 전문 인용이 발생하는 유일한 지점은 F7 "오늘의 말씀"이다. 여기는 ① 저작권이 만료된 것으로 이해되는 개역한글판(1961) 사용 또는 ② 대한성서공회 개역개정 라이선스 계약으로 해결한다. v1은 ①로 시작 (출시 전 법률 확인 1회 필요). F9 검증기의 내부 참조 성경도 같은 이유로 개역한글 기반이면 충분하다 — 검증이 자구가 아닌 내용 대조이므로 번역본 차이가 판정에 영향을 주지 않는다.

## 5. 콘텐츠 전략

- **출제 철학 (최상위 원칙): 퀴즈는 성경의 '내용'을 묻는다.** 인물·사건·사실·가르침에 대한 이해를 측정하며, 본문 자구를 그대로 묻는 암송형 문제(구절 빈칸 채우기, 토씨·어순 맞히기)는 출제하지 않는다. 이 원칙 덕분에 번역본 간 표현 차이에 강건하고, 번역문 저작권에서도 자유롭다
- 표기 기준: 인명·지명·용어 표기는 **개역개정 표기**로 통일 (설정 화면에 고지). 본문을 인용하는 것이 아니라 "아브라함/압라함" 같은 표기 혼선을 막기 위한 표준
- 출제 범위: 사실 기반(인물·사건·지명·구절 출처)으로 한정. **교리·해석 문제 출제 금지** (세례/침례, 종말론 등 교단 간 쟁점은 리뷰 테러와 커뮤니티 분쟁의 최대 리스크)
- 초기 문제 풀: 출시 시점 3,000문항 (난이도별 4:4:2). 무제한 풀이 모델은 콘텐츠 소진 속도가 빠르므로 월 500문항+ 증분 필수
- 생산 파이프라인: LLM 초안 생성 → 근거 구절 내용과의 사실 정합성 자동 검증 → **신학 전공자 검수** (외주 1인) → 배포. 기존 시험문제 대량 생성 파이프라인 자산 재활용
- 품질 원칙: 모든 문제에 근거 구절 필수 (F9 자동 검증의 전제 조건). 오류 신고·자동 격리·수리 파이프라인은 F9 참조

## 9. 오픈 퀘스천

1. 앱 이름 확정 — 후보: 말씀퀴즈, 말씀골든벨(상표 검토 필요), 성경대전. 타깃 세대 정서에 맞는 네이밍 테스트 필요
2. 교회 점수 산식의 "상위 20명" 숫자 — 파일럿에서 10/20/30명 밸런스 검증
3. 가톨릭 확장 여부 — 성경 범위(외경)와 용어가 달라 v1은 개신교 한정, 수요 확인 후 별도 모드 검토
4. 주간 리셋 요일 — 월요일 00시 vs 주일 예배 후(일요일 저녁). 타깃의 주간 리듬상 후자 검토 여지
5. 구독 연간 플랜 프로모션 시점 — 출시 즉시 vs 리텐션 안정화 이후
6. "오늘의 말씀" 번역본 — 개역한글(저작권 자유, 다만 문체가 오래됨) vs 개역개정 라이선스 계약(타깃 세대에게 가장 익숙한 번역). 퀴즈는 내용 기반이라 이 결정과 무관
