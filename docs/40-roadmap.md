# 40. 사업 실행 로드맵 (Milestone → Phase → SubTask)

> 본 문서는 PRD v1.0(2026-07-12)·갭분석·13개 파트 실무문서를 단일 실행 계획으로 통합한 프로그램 리드(Step 4) 산출물입니다. 버전 스코프(파일럿 → v1.0 → v1.1 → v1.2 → v2.0)를 마일스톤 골격으로 삼되, 앞단에 **M0(사전 준비)** 를 추가했습니다. 모든 일정은 개발 킥오프(**T0**) 기준 상대 주(週) 표기입니다.

### 40.0.3 크리티컬 패스(직렬) vs 병렬 트랙

```
[크리티컬 패스] ── 이 사슬이 밀리면 출시 전체가 밀린다
 성서공회 라이선스 방향 확정(L0/L1/L2)  →  scripture_text 저장·표시 설계
        │
 백엔드 리드 채용(T-12 착수)  →  서버권위 채점·리더보드 엔진  →  클라 온라인 채점  →  파일럿 빌드  →  파일럿  →  출시
        │                                                                  ↑
 3,000문항 생산·신학 검수(T-12~T+4, 신학자 SPOF가 병목)  ──────────────────┘
```

**병렬 가능 트랙(크리티컬 패스와 독립적으로 진행):**
- 브랜딩/상표 출원, 디자인 토큰·티어 아트워크
- 교회 DB 시딩(500~1,000 verified)
- 법무 부속 체크리스트(사업자등록·통신판매업·게임물 등급)
- 데이터 택소노미 설계·분석 스택 프로비저닝
- 마케팅 GTM 자산·파일럿 협력교회 BD
- 수익화 광고/구독 SDK 통합(서버 계약 확정 후)

## M0 — 사전 준비·기반 구축 (T-12주 ~ T0)

**목표:** 개발 착수 전 존재 리스크(법무 블로커·SPOF·미확정 의사결정)를 제거하고, 콜드스타트 자산(콘텐츠·교회DB)과 기술 기반을 확보한다.

**성공기준(정량 KPI 게이트 = G0):**

- [ ] 오픈퀘스천 6종 중 출시 블로커(앱명, 번역본, 라이선스 방향) 확정
- [ ] 성서공회 라이선스 협상 착수(T-4주) 및 폴백(L1/L2) 설계 완료
- [ ] 상표 선행조사(KIPRIS) 완료 · 클래스 9·41·42 출원 접수
- [ ] 백엔드 리드 온보딩(T-12 착수) · 신학 검수 리드+백업+편집보조 계약
- [ ] 콘텐츠 3,000문항 생산 파이프라인 가동(주간 생산율 목표 확정)
- [ ] 교회 DB 시딩 500~1,000 verified 확보 경로 확정 및 착수
- [ ] 이벤트 택소노미 v0 · 클라우드(GCP 서울) 프로비저닝 · CI/CD 스캐폴드
- [ ] 시드 조달 1차(₩8억~) 클로징 또는 런웨이 확정

**핵심 Phase:** P0.1 경영 의사결정 · P0.2 법무 기반 · P0.3 브랜딩/디자인 기초 · P0.4 조직/예산 · P0.5 콜드스타트 콘텐츠 · P0.6 교회 DB 시딩 · P0.7 기술 기반/데이터 택소노미
